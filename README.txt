KERA RAVEN — Link Hub
=====================
Static site: no build step, no backend.

Files
  index.html            page markup + all 5 links (order: Kick, YouTube, Instagram, TikTok, Facebook)
  style.css             design, animations, responsive rules
  script.js             tiny fallback script
  kera-raven-logo.png   transparent logo mark (replace to update)
  kera-raven-bg.png     background (portrait; replace to update)
  favicon.png           tab icon

Use
  Open index.html locally, or upload the whole folder to any static host
  (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

Notes
  - Fonts (Rajdhani, Space Grotesk) load from Google Fonts; offline it falls back to system fonts.
  - Edit links/descriptions directly in index.html.
  - Colors are CSS variables at the top of style.css.
